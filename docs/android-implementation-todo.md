## 残作業（2026-09-06）

P0 は外部テスト配布前、P1 は一般公開前に完了する。チェックは各項目の完了条件を満たしてから付ける。Android 15 エミュレーターでの成功を、実機・他OS・他ブラウザの保証に広げない。

### P0 — 配布前の実装・検証

- [ ] **AND-01: GitHub Actions の確認** — main に統合した Android CI の結果を確認し、失敗を修正する。完了条件: main の対象コミットのビルド・テスト・lint成功を確認した記録。ローカル検証は完了しているが、GitHub CLIが未認証のためリモートCI結果は未確認。
- [ ] **AND-02: UIの残差を仕上げる** — iOS/Android の選択内容・日時・タイムゾーンを揃えて再比較し、意図しないカード高さ・余白・改行差を修正する。ホーム、確認、実行中、対象選択、編集、設定を対象にする。完了条件: 対応する比較画像と、許容するOS固有差分の一覧。
- [ ] **AND-03: OS互換性を確認する** — minSdk端末と主要Androidバージョンで、初回設定、アラーム権限、戻る操作、画面端の余白、バックグラウンド復帰を試す。完了条件: OS別のチェック結果と、不具合修正後の再確認。
- [ ] **AND-04: Pixel/Galaxy実機で継続動作を確認する** — 消灯、Doze、省電力、端末再起動、アプリ更新、時刻・タイムゾーン変更を含め、予約開始・遮断・終了を検証する。完了条件: 両機種の長時間試験ログ、電池消費、予約と実行中ロックの復元結果。
- [ ] **AND-05: 権限喪失・保存異常からの復旧を確認する** — ユーザー補助の切断／取消、アラーム許可取消、強制停止後の起動、保存データの破損を専用テスト環境で試す。完了条件: 状態表示と復旧導線が正しく、データを不用意に上書きせず、正常復旧後に予約・解除が動く。
- [ ] **AND-06: Android 17の高度な保護を確認する** — 有効／無効の両条件で権限取得・遮断・復旧を試す。完了条件: 対応可否を実測で記録し、非対応ならアプリ内説明と配布対象へ反映。
- [ ] **AND-07: ブラウザ対応表を確定する** — Chrome/Firefox の通常タブ、アドレス欄非表示、シークレット、カスタムタブ、ブラウザ更新時を検証する。完了条件: ブラウザ・バージョン・状態別の遮断/解除結果と、アプリ内の対応範囲説明が一致。
- [ ] **AND-08: アクセシビリティを仕上げる** — TalkBack、最大文字サイズ、表示サイズ変更、横画面で全操作を確認する。特に横スクロールのモード/プリセット、曜日選択、固定保存ボタン、モーダルのフォーカスを確認。完了条件: 読み上げ・移動・保存・取消を操作でき、文字切れや到達不能な操作がない。
- [ ] **AND-09: 制限対象外の境界を確定する** — 分割画面、PiP、通知返信、仕事用プロファイル、新規アプリと未分類カテゴリを試す。完了条件: 制限できる範囲とできない範囲を文書化し、アプリ・FAQ・ストア説明へ反映。
