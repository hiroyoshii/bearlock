## 自動テストの範囲

`BearLockPurchases` スキームは専用iOSテストホストで、本番の `SupportStore.swift` をそのままコンパイルする。StoreKit Testingのローカル商品を使い、StoreKitの商品取得・購入・取引監視・完了処理を呼ぶ。テストは共有StoreKit環境を変更するため直列実行する。

1. 3商品の取得と各2回の購入、完了後に未完了取引が残らないこと
2. 商品未取得時に購入しないこと
3. 購入の強制エラー後、テストサーバーを通常状態に戻すと同じサービスから購入できること
4. キャンセルで成功表示や購入済み取引を作らないこと
5. 保留購入を承認すると監視処理が完了させること
6. サービスが停止中に作成された未完了取引を次のサービス起動で回収すること
7. 無関係な商品を応援購入として完了させないこと

6はサービスの再生成を検証しており、OSによるアプリ終了・再起動のテストではない。未検証の署名エラー、実ストアの商品価格・販売状態、実際の決済認証、アプリ終了中の配送はTestFlight/Sandboxで別途確認する。テスト用の固定価格は本番の商品設定の証拠ではない。
