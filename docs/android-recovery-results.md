# Android 復帰処理の修正と追試

2026-09-06。方式B（Accessibility）の試作を修正し、Pixel_9a AVD / Android 15（API 35）/ x86_64 で追試した。compileSdk / targetSdk は36。iOS のソースは変更していない。

## 変更

サービス接続・予約更新・ウィンドウ変更時に、現在のフォーカスウィンドウ（なければアクティブウィンドウ）のルートからパッケージ名を取得し、保存済みの対象と開始・終了時刻を再照合する。自分の Accessibility Overlay は候補から除外する。

取得処理は別スレッドで行い、一時的に取得できない場合は最大8回試みる。処理中に新しいイベントが来た場合やサービスが終了した場合は、古い結果を反映しない。常時UsageStatsを問い合わせる方式は追加していない。

この処理のため `canRetrieveWindowContent` と `flagRetrieveInteractiveWindows` を宣言し、試作の権限説明・同意文も更新した。コードが読むのはルートのパッケージ名のみで、本文・入力内容・子ノードは読まない。ネットワーク権限もない。

## 再接続試験

[再接続の生ログ](qa/android-recovery/reconnect-events.json)。60秒ロックを作成後、一度監視を無効にして対象アプリを開き、操作できることを確認。そのまま監視を再接続し、対象を開き直さずに復帰を確認した。

| 条件 | 結果 |
| --- | --- |
| 監視無効中の対象タップ（陽性対照） | 1回届いた |
| 接続前から開いていた対象の遮断 | ブロック画面を確認、試験タップは届かない |
| ホーム移動・対象への再入場 | ホームで除去、対象に戻ると再表示 |
| 保存された終了時刻の到来 | ブロックを除去、試験タップが届く |
| 終了後にさらにサービスを再接続 | 再遮断されず、試験タップが届く |

この実行では再接続時の表示イベントも届き、初回のブロック追加はスナップショット完了より前だった。したがってこの試験単独で「表示イベントが一切届かない場合」を証明したとはしない。現在の対象を取得できたことは別途 `foreground_snapshot` で確認している。

[復帰したブロック画面](qa/android-recovery/reconnected-active.png)、[ホーム移動後](qa/android-recovery/home-after-recovery.png)、[終了後](qa/android-recovery/expired.png)。

## 既存条件の回帰試験

通常起動3回、対象を開いたまま予約開始、開始前に消灯・強制Dozeから復帰、対象側の通常オーバーレイ拒否の計6件を再実行。**6/6で期間中の試験タップを遮断し、6/6で終了後のタップが届いた。** [生ログ](qa/android-recovery/b-regression-events.json)。

## 端末再起動試験

240秒ロックで実施。対象の起動完了後にサービスが接続し、スナップショットから対象を取得してブロックを追加したログがある。しかし、その後 System UI の応答停止ダイアログが割り込み、終了後の試験タップが届かなかった。**端末再起動全体の試験は合格としていない。**

期間中の最初のスクリーンショットにもブロックは写っておらず、追加・除去のログが続いている。`overlay_added` だけで継続的な遮断ができたとは判定しない。エミュレーターの再起動直後の不安定さと製品側の挙動を分離するため、安定した環境での再試験が残る。

[再起動の生ログ（passed=false）](qa/android-recovery/reboot-events.json)、[期間中の観測画面](qa/android-recovery/reboot-active-observation.png)、[終了後のSystem UI応答停止](qa/android-recovery/reboot-system-ui-anr.png)。

## 検証の範囲

アプリの assembleDebug、単体テスト6件、lintDebug は成功。追加の3テストは、古い結果によるホーム移動の上書き、サービス終了後の結果反映、遅い読み取りの並列蓄積を防ぐ確認。既存の試作向けlint警告は残る。

1回ずつの入力試験であり、全フレームで操作の隙間がないことや性能・電池消費の保証ではない。実機、メーカー別省電力、Android 17、分割画面/PiP、Webサイト・カテゴリは未検証。前回の資料は [比較結果](android-comparison-results.md) に残した。
