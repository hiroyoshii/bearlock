# Android製品実装と画面確認

> 初期実装時点の検証記録。現在の UI・入力範囲・追加検証は [iOS UI 整合](android-ui-parity.md) と [新スクショ比較](../ANDROID_SCREENSHOTS.md) を参照。通常の即時／遅延／日時指定 UI は 15〜720 分、繰り返しは最大24時間。

2026-09-06。比較用アプリを保存し、`android-lab/product` に製品用モジュールを追加した。iOSソースの動作は変更していない。iOSの熊画像をAndroidリソースとして再利用。

## 実装範囲

複数対象、アプリ検索、ドメイン登録、端末カテゴリ、即時/遅延/日時指定/曜日繰り返し、予約編集・削除、重複拒否、開始後の変更禁止、履歴3件・ピン・削除、日英UIと言語設定、ローカル診断、権限説明・復旧、ブロック画面。

実行中セッションを予約ルールから分離し、繰り返し予定を変更しても現在の対象・終了時刻を変えない。保存はスキーマ1のAtomicFile。壊れた保存データを空データで上書きしない。終了済みセッションは時刻を巻き戻しても再生成しない。

1回1分〜24時間、日時指定は1年先まで。iOSの即時/遅延/日時指定UIの上限12時間を含む範囲を実装した。繰り返しは保存時のタイムゾーンを使い、夏時間の欠落時刻は次の有効時刻へ移す。

## Webとカテゴリの提供範囲

WebはChrome/Firefoxの既知のアドレス欄だけを参照するアダプターを実装。Webロック実行中以外はアドレス欄を取得しない。本文・パスワードを読まず、URLや閲覧履歴を保存しない。非表示のアドレス欄、編集フォーカス中、未対応ブラウザはドメイン判定できない。VPN/DNSによる通信遮断は実装していない。

カテゴリは端末のApplicationInfo.categoryを使う。分類未設定のアプリは個別選択を案内し、新規インストールした同カテゴリのアプリにも適用する。Appleのカテゴリと同じ集合になるとは保証しない。

## ローカル検証

- `:product:assembleDebug` / `:product:assembleRelease` 成功。署名用環境変数がないためreleaseは未署名。
- `:product:testDebugUnitTest` 12件成功。区間境界、複数対象、重複・隣接、変更禁止、親編集/削除、日跨ぎ、DST、失効、時計巻き戻し、履歴、ドメイン一致を確認。
- `:product:lintDebug` 成功。API互換属性、アイコン、文字列構成の警告は公開準備で整理する。
- CI定義追加。GitHub上での実行・ストア配信は行っていない。

## エミュレーターで確認した操作

Pixel_9a / Android15 API35、Chrome 152.0.7977.75。ADBで製品用のユーザー補助サービスと正確なアラームを許可。独立した同意画面の表示・同意操作も確認した。

- **アプリ遮断**: 実際のProbeボタンへ、ロック前にタップが届くことを確認。1分ロック中のタップは届かず、終了後には再び届いた。実行中ホーム・予約画面への移動と対象への再入場も実施。
- **Web遮断**: UIからexample.comを登録し1分ロックを作成。Chrome通常タブでWeb用のブロック画面を確認。期間中に背後のLearn moreリンクの位置をタップしても画面は進まず、終了後には同じリンクからIANAページへ遷移できた。Chromeのこの1バージョン・通常タブでの確認であり、他ブラウザや隠れたアドレス欄まで保証しない。
- **予約UI**: 曜日指定の作成→確認→保存→再表示→編集（30分から60分）→再保存まで実施。保存JSONの対象・曜日も確認。試験終了時にUIから予約を削除し、試験ロックが残っていないことも確認した。
- **日本語/英語**: 言語設定を変更し、ホームと作成画面を撮影。日本語の選択が遮断画面にも反映されるよう修正。
- **ビルド**: 製品12件＋比較用6件の単体テスト成功。debug APK、未署名release APK、未署名release AABを作成。release manifestにQA入口とInternet権限がないことを検査。

ブロックの測定中はUIAutomatorの画面ツリー取得を使わず、screencapと対象側ログで判定した。ツリー取得が他のAccessibilityサービスを中断・再接続させるため。UIの操作・構造確認には測定外でUIAutomatorを使用した。
