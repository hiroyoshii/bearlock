# 常時ロック画面

常時ロックを使う人の操作順に並べたスクリーンショットです。iOSシミュレータ上で、アプリの同じ画面を表示しています。ロック状態と翌日予約は画面確認用のサンプルデータです。

1. `00-target-selection.png` — ホーム上部でロック対象を選ぶ。
2. `01-always-create.png` — 「つねに」を選び、解除枠を決めて「ロック開始」。
3. `02-always-locked.png` — 設定後のカード。今日の残量と5/10/15分解除。
4. `03-always-temporary-unlock.png` — 一時解除中。再ロック時刻と「一時解除を終了」。
5. `04-always-empty.png` — 今日の残量0分。取得済み枠がないためロック中。
6. `07-next-day-reset.png` — 翌日。今日の解除枠が新しく戻る。
7. `08-edit-settings.png` — ホーム内の常時ロックカードがその場で編集欄に展開。上限・対象の変更予約、または「明日から停止」。
8. `05-always-pending-change.png` — 変更予約中。今日の設定・残量を保ち、翌日から反映。
9. `06-always-stopped.png` — 停止後。設定を保持したまま停止中。
10. 停止後も同じカードの「編集」から「明日から再開」を選べる（停止中カードは `06-always-stopped.png`）。

Screen Timeの実際のShield適用・再ロックはシミュレータ画面では検証できません。実機確認の対象です。
