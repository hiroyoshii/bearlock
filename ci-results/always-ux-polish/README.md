# Always Lock UX polish

Japanese iPhone simulator screenshots. “Before” screenshots are the saved pre-polish UI. “After” screenshots were captured by the current UI tests.

- `before-always-card-ja.png` / `after-always-card-ja.png`: removes the target-count summary, emphasizes the remaining allowance, explains manual early-end returns, and marks the paid timed-unlock entry with a card icon.
- `before-edit-ja.png` / `after-edit-ja.png`: clarifies that today's lock remains active while changes are scheduled for tomorrow.
- `early-end-return-en.png`: shows the configured-list balance after manually ending a free unlock early.

Manual early end returns the unused full minutes in one state save; seconds are discarded. Natural expiry does not return minutes. Paid timed unlocks neither consume nor replenish the free daily allowance.

- `always-settings-with-overview-ja.png`: shows the new overview sentence in the “つねに” creation form.
